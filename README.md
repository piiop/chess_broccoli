# chess_broccoli
Tiny Chess Engine
A lightweight chess engine developed for a Kaggle competition, designed to operate under strict resource constraints. This engine demonstrates efficient chess algorithms while adhering to tight memory and processing limitations.
Competition Constraints

Memory: 5 MiB RAM limit
Processing: Single 2.20GHz CPU core
Size: 64 KiB compressed submission size limit

Project Status
🚧 Work in Progress 🚧
This engine is currently under development. Features and optimizations are being implemented to maximize performance within the competition constraints.
Technical Details
This engine is written in C/C++, focusing on minimal resource usage while maintaining competitive gameplay capabilities. By working within the strict competition constraints, the implementation emphasizes efficient memory management and optimized algorithmic approaches.
